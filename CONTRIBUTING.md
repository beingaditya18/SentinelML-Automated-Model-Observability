# Contributing to SentinelML

Thank you for your interest in contributing to SentinelML! We welcome contributions to improve model observability, telemetry collection, and documentation.

## Code of Conduct
Please follow our standard Code of Conduct when interacting with contributors and maintainers.

## How to Contribute
1. **Fork the Repository**: Create a personal copy of the repository on GitHub.
2. **Set up Environment**: Install dependencies using python requirements and configure environment parameters in `.env`.
3. **Write Code**: Implement your additions or bug fixes. Please match styling guidelines.
4. **Write Tests**: Ensure any logic additions have proper pytest validation coverage.
5. **Run Verification**: Ensure lint checks and all pytest scripts pass successfully.
6. **Submit PR**: Open a Pull Request referencing the issue you are addressing.
