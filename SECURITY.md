# Security Policy

## Supported Versions

We actively provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project (specifically surrounding pickle serialization or SQL injection issues), please do NOT open a public GitHub issue. Instead, report it privately to the maintainers at aditya.mandloi@example.com (or via GitHub security advisories if active).

We will investigate and publish a patch inside a secure timeframe.
